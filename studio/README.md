# PGT Studio

Среда разработки для языка PGT на C++ и Qt 6.

## Сборка

```sh
cmake -S studio -B studio/build -G Ninja
cmake --build studio/build
./studio/build/pgt-studio [папка-проекта | файл.pgt]
```

Нужен только Qt 6 (Widgets); LLVM для студии не требуется. Компилятор `pgt` собирается отдельно (см. корневой `CMakeLists.txt`).

## Что умеет

- редактор с подсветкой PGT, номерами строк, автоотступами и вкладками;
- дерево файлов проекта;
- новый проект из шаблонов `pgt new` (Ctrl+Shift+N), открытие проекта и недавние проекты;
- сборка (Ctrl+B) и запуск (F5) с выводом в панель; двойной клик по ошибке открывает файл на нужной строке;
  строка ввода внизу передаёт текст запущенной программе (для `input()`);
- дерево проекта как в VS Code: клик открывает файл; переименование (F2), удаление (Delete, в корзину),
  новые файлы и папки, копирование пути — через контекстное меню;
- панель «Компилятор»: токены и синтаксическое дерево текущего файла прямо во время набора
  (`pgt build - --debug=json`), клик по токену или узлу переходит к месту в коде, токен под курсором подсвечивается;
- настройки (Ctrl+,): путь к компилятору с проверкой `pgt --version`, шрифт, ширина отступа, папка проектов.

Если путь к компилятору не задан, студия ищет `pgt` в `PATH`, рядом с собой и в `../../build/pgt` (сборка из исходников).

## Тема

Только тёмная. Все цвета интерфейса и подсветки заданы в одном месте — `src/Theme.h`; иконки (стрелки, крестики, галочки) рисуются из этих цветов при запуске. Системные диалоги отключены, чтобы светлая тема рабочего стола не просочилась в файловые окна.

## Устройство

| Файл | Назначение |
|---|---|
| `src/Theme.*` | палитра, стиль и иконки тёмной темы |
| `src/MainWindow.*` | главное окно: меню, панели, проекты, сборка и запуск |
| `src/CompilerPanel.*` | токены и дерево разбора от `pgt --debug=json` |
| `src/OutputPanel.*` | вывод процессов, переход к ошибкам, ввод для программы |
| `src/editor/CodeEditor.*` | редактор кода |
| `src/editor/PgtHighlighter.*` | подсветка синтаксиса |
| `src/project/NewProjectDialog.*` | создание проекта через `pgt new` |
| `src/settings/*` | хранение настроек (QSettings) и диалог настроек |
